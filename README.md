# mouain_v1.2

## قاعدة البيانات
يستخدم التطبيق قاعدة `school_data.db` بصيغة SQLite العادية من دون تشفير. احفظ نسخة احتياطية من الملف واحمه وفق إجراءات الجهاز الذي يحتويه.

يُحدّد مسار قاعدة البيانات بجانب ملفات التطبيق أو الملف التنفيذي، وليس اعتمادًا على مجلد التشغيل الحالي؛ لذلك يبقى التطبيق متصلاً بقاعدة البيانات نفسها عند تشغيله من اختصار أو من مجلد آخر.

تُطبّع بيانات الحصص ومخططات التدريس عند تشغيل التطبيق المحدّث: يرتبط المجال ونمط التعلم بمعرّفات جداول مرجعية، وتُحفظ أيام التدريس في جدول مستقل بعلاقة واحد إلى متعدد. قبل ترحيل قاعدة قديمة، ينشئ التطبيق نسخة احتياطية مستقلة بجوارها بامتداد `.bak`، ويتوقف مع رسالة خطأ إذا تعذّر الترحيل بدلاً من إسقاط البيانات بصمت. وتبقى ملفات JSON متوافقة، إذ تستمر الأيام والأسماء فيها بصيغها النصية المعتادة.

تُحفظ الأقسام في جدول `classe` وترتبط بالمستوى الدراسي في جدول `level`؛ وتُرحّل الأقسام المسجلة تلقائيًا عند تشغيل الإصدار المحدّث.

تتيح صفحة **المخططات** إنشاء مخطط مرتبط بالقسم والمجال وكفاية المجال. قبل تخطيط الحصص، تُضبط أنشطة المخطط وكفاياتها ومكوّنات الكفاية والمحتويات من نافذة الإعداد؛ وتُقترح البيانات المسجلة في البرامج الرسمية مع السماح بإدخال بيانات يدوية دون تعديل تلك البرامج. الأهداف المميزة اختيارية، ويمكن ربط أكثر من مكوّن ومحتوى بالنشاط. لا تتاح إدارة الحصص حتى يُحفظ نشاط واحد على الأقل وتُستكمل كفايته ومكوّناته ومحتوياته. يُقترح عدد المخطط بعد حفظ نشاطه ويمكن تعديله من نافذة إعداد الأنشطة؛ ويكون الترقيم مستقلاً بحسب القسم والمجال والنشاط، باستثناء اللغة العربية حيث تشترك أنشطتها في تسلسل واحد، ويمكن إعداد أنشطة متعددة لكل مخطط. يمكن إضافة خصائص مسماة من المستخدم للمخطط وللحصة، وإدارة العطل الرسمية بفترة من تاريخ إلى تاريخ؛ وعند إنشاء المخطط أو تعديله تُحدد أيام التدريس وعدد الحصص الأسبوعية لكل يوم. يُحسب تاريخ النهاية وفق هذا الجدول مع تجاوز أيام العطل، وتُعامل بيانات المخططات القديمة وملفات JSON التي لا تتضمن أعداداً يومية على أنها حصة واحدة لكل يوم محدد. النمط المنهجي بنسبة تقارب 75% توجيهي لا يفرض توزيعاً آلياً.

يمكن تصدير المخطط المحدد إلى PDF من زر صفحة المخططات؛ يُحفظ الملف تلقائيًا في مجلد Documents الخاص بالنظام باسم يتضمن نشاط الترقيم ورقم المخطط والقسم. يكون الملف أفقيًا بهوامش صغيرة للطباعة، ويعرض كفايات الأنشطة ومقدمة الوحدة عند توفرها، ثم حصص أنماط التعلم الأربعة. تُختصر مكونات الكفاية برموز ويُضاف مفتاحها في نهاية الملف، تليه وضعية الاستكشاف عند توفرها. كما تتيح قائمة المخططات صفحة **عرض المخطط** لمعاينة المحتوى داخل التطبيق بجداول تعريفية وبطاقات للأنشطة.

لإنشاء بيئة المشروع وتشغيل التطبيق:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

يمكن إنشاء نسخة SQLite مستقلة باستخدام `export_database.py`.
